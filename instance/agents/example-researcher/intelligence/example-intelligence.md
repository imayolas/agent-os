# Example Intelligence — How This File Type Works

> Demonstration file. Replace with real intelligence — durable knowledge about how your domain works — or delete it.

Intelligence files capture **what we know to be true about how the world works**: external principles, market facts, domain expertise. They are distinct from strategy (what we'll do) and projects (work in progress).

## Key properties (each header = one distinct insight)

- **Living, not append-only.** When new evidence contradicts an entry, rewrite or delete it — don't keep both.
- **Actionable.** If an entry doesn't change how an agent thinks or acts, it doesn't belong here.
- **Sourced.** Cite the source URL or the data + date the insight came from.
- **A hypothesis, not a fact.** Intelligence informs reasoning; it never replaces it. See `CLAUDE.md` → Cognitive Discipline.
